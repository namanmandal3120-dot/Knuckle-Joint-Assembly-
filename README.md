## About the Knuckle Joint
A knuckle joint is a mechanical fastening arrangement used to connect two rods subjected primarily to tensile forces. It permits a limited angular movement between the connected rods.

Typical applications include:
- Tie rods and tension links
- Connecting mechanisms
- Mechanical linkages
- Certain structural and industrial assemblies

## Main Components
A conventional knuckle joint consists of the following components. The exact components and details depend on the drawing included in this repository.

1. Single-eye end
2. Fork or double-eye end
3. Knuckle pin
4. Collar
5. Taper pin or locking arrangement
